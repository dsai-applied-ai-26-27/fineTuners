{% if refused.kind == "conflict" %}

{% icon "warning" %}Not taken in: the course changed on the site after you took your copy.

Someone added to it, or the owner published a change. Your zip does not have those lines, so taking it in would remove them. Put your work on top of the latest version, in the kit's folder:

git stash
# download the course files again (the button above)
uv run tools/unpack.py {{ course.slug }}.zip
git stash pop
uv run tools/pack.py {{ course.slug }}

git stash sets your work aside, unpack.py brings in the site's version, and git stash pop puts your work back on top. If git marks a conflict in a file, both versions are in it between <<<<<<< and >>>>>>>: keep both sets of lines, delete the markers, or ask your assistant to. Then hand in the new zip.

{% elif refused.kind == "removal" %}

{% icon "warning" %}Not taken in: it removes or rewrites what is already there.

A hand-in may only add. Put the lines below back as they were (git diff shows what you changed, git checkout -- <file> restores a file), then pack and hand in again. If something on the site is wrong and has to change, say so with Ask or report. If you did not touch these lines, the course changed on the site: download the course files again and put your work on top (how).
