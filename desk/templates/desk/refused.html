{% if refused.kind == "confirm" %}

{% icon "warning" %}Not taken in yet: this hand-in removes or rewrites what is on the site.

That is allowed, but it has to be meant. Look at what would go, below. If it is what you want, choose the zip again, tick It may change and remove what is there, and hand in. If it is not (an assistant tidying up where it should not have), git diff shows what changed and git checkout -- <file> puts a file back; then pack again.

{% elif refused.kind == "conflict" %}

{% icon "warning" %}Not taken in: the course changed on the site after you took your copy.

Someone else handed something in, or the owner published a change (the list below shows the latest steps). Taking your zip in would undo that. Put your work on top of the latest version, in the kit's folder:

git stash
# download the course files again (the button above)
uv run tools/unpack.py {{ course.slug }}.zip
git stash pop
uv run tools/pack.py {{ course.slug }}

git stash sets your work aside, unpack.py brings in the site's version, and git stash pop puts your work back on top. If git marks a conflict in a file, both versions are in it between <<<<<<< and >>>>>>>: decide what stays, delete the markers, or ask your assistant to. Then hand in the new zip.

{% elif refused.kind == "start" %}

{% icon "info" %}Not taken in: the site does not know which version you started from.

Press Download the course files above and unpack them into the kit with uv run tools/unpack.py {{ course.slug }}.zip (after git stash, if you have work already; git stash pop puts it back). From then on the site knows your starting point and can tell whether the course has changed under you.

{% elif refused.kind == "owner" %}

{% icon "warning" %}Not taken in: it changes what is not yours in course.yaml.

In course.yaml the topics and the description are yours. Put the rest back as it was; a topic's id cannot be changed or removed.

{% elif refused.kind == "invalid" %}

{% icon "error" %}Not taken in: the site's check found errors.

These are things tools/check.py cannot see: links between files, the text itself, the maths. Give this report to your assistant, fix, pack and hand in again.
